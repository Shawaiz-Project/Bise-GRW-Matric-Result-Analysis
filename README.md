# SSC Result Analytics Dashboard

A responsive multi-page-style dashboard built with **HTML, CSS, JavaScript, Chart.js, SheetJS, and a Web Worker**.

The dashboard reads the Excel workbook generated by `pdf_result_to_excel.py` and provides:

- Overview KPIs
- Pass/fail doughnut chart
- Full status chart
- Marks distribution chart
- Grade distribution chart
- Candidate-type comparison
- Top failed subjects
- Part-I versus Part-II slip comparison
- Largest schools
- Best school pass rates
- Student search by roll number, name, school, status, grade, marks, and subject
- Student detail modal
- Filtered CSV export
- School analysis page
- Subject analysis page
- Automatic insights page
- Data-quality page
- Light and dark themes
- Responsive mobile navigation

## Required workbook sheets

The dashboard is designed for the workbook produced by the supplied Python converter. It expects these sheets when available:

- `Students`
- `Status_Summary`
- `Subject_Failures`
- `Marks_Distribution`
- `Top_Students`
- `Candidate_Type`
- `Institute_Summary`
- `Data_Quality`

The `Students` sheet is required. Other sheets are used for charts and summaries.

## Run the dashboard

### Option 1: Convenience server

1. Extract the ZIP file.
2. Open Command Prompt or PowerShell inside the extracted `ssc_result_dashboard` folder.
3. Run:

```bash
python serve_dashboard.py
```

The browser should open automatically at:

```text
http://localhost:8000
```

### Option 2: Standard Python server

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Do not open `index.html` directly with a `file:///` address. The worker and CDN-loaded spreadsheet parser work more reliably through a local HTTP server.

## Load the Excel workbook

1. Click **Choose Excel file**.
2. Select `MA_2026_results_analysis.xlsx`.
3. Wait until the progress bar reaches 100%.
4. Use the left navigation to open Overview, Students, Schools, Subjects, Insights, or Data quality.

The large `Students` sheet is parsed in a Web Worker so the interface remains responsive. Search results are paginated and only the visible page is rendered.

## Student CSV export

The **Export filtered CSV** button applies the current student filters. For browser stability, one export is limited to 50,000 matching records. Narrow the filters and export multiple files when more records are required.

## Internet requirement

The default project loads:

- Chart.js 4.5.1 from jsDelivr
- SheetJS Community Edition 0.20.3 from the official SheetJS CDN

An internet connection is therefore required when the dashboard starts. The selected workbook is parsed in the browser and is not posted by this project to an application backend.

## Customize colors

Edit the CSS variables at the top of `css/styles.css`, especially:

```css
--primary: #2457d6;
--success: #12805c;
--danger: #c33a4b;
--warning: #ae6c00;
```

Chart colors are defined near the top of `js/app.js` in the `chartPalette` array.

## Important validation note

The dashboard displays values extracted into the workbook. For unusual, disputed, or high-stakes candidate records, compare the student detail's raw result and PDF page number with the original result gazette.
